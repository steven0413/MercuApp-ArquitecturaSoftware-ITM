# MercuApp - Plataforma de Gestión Logística de Última Milla

## Resumen ejecutivo

MercuApp es una propuesta académica del ITM para centralizar la gestión de pedidos y entregas de una empresa de retail digital. El problema que aborda es la falta de coordinación entre canales de venta, inventarios distribuidos, tiendas y repartidores, que puede causar pedidos duplicados, ventas de productos agotados y poca trazabilidad para el cliente.

El alcance inicial va desde la recepción del pedido hasta la entrega o el registro de una incidencia. La propuesta prioriza evitar pedidos duplicados y sobreventas, consultar el estado de las entregas y proteger los datos de clientes. Para esta etapa se propone un monolito modular con límites claros entre Ingesta, Órdenes, Inventario, Logística y Soporte.
